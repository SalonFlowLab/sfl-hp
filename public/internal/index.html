デザイン・運用ルール

  • 色：ブランド6色（#F8F5EF #103A71 #C99A1A #E7D3A0 #1E88E5 #333333）＋フッターだけ中間の青 #1A5796。主ボタンは紺、金は線・番号などの装飾だけ（文字色には使わない＝コントラスト確保）。
  • 文字：Noto Sans JP、本文16px・行間1.85。太字の文章を並べない。見出しの句読点なし。
  • ボタン：角丸6px・高さ52px（小44px）。カードはカード全体を押せる形。
  • 開閉：追加説明だけ。見出し行全体を押せる＋／−表示。概要・実績・会社情報は常時表示。
  • アニメーション：セクション登場時のフェードのみ。視差効果を減らす設定の端末では無効。
  • CTA：主CTAは「60分無料相談」。ヘッダー・FV・ページ末尾だけに置き、本文で同じボタンを重ねない。問い合わせページには末尾CTAを置かない。
  • 共通部品（事業・講座・実績・相談フロー・ナビ・フッター）は public/assets/site/js/data.js を直せば全ページに反映。JSON-LD は静的なので同時に直す。
  • 検査：npm run check（ページ間アンカーまで検査）＋ git diff --check ＋ ブラウザ確認。
  • この内部ページ：functions/internal/_middleware.js がプレビューURL（<ブランチ>.<project>.pages.dev）とローカルだけ通し、本番ドメインと <project>.pages.dev では404。注意：本番デプロイにも固有のハッシュURLが発行されるため、そのURLでは表示される（noindex・no-store）。
